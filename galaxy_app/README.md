# 📱 E0509 갤럭시 전용 리모트 컨트롤러 (Android APK & PWA)

두산 협동로봇 **E0509 비전 피킹 시스템**을 동일 Wi-Fi 대역의 **삼성 갤럭시(Android)** 스마트폰에서 원격 제어·모니터링하는 전용 어플리케이션입니다.

---

## 1. 핵심 기능

1. **스캔 모드 우선순위 제어 (토글 스위치)**:
   - **`📡 전용 리더기 우선 모드 (기본값)`**: `ACR1555U` 외장 리더기 및 로봇팔 직접 라벨 스캔이 주력으로 동작하며, 휴대폰 자체 NFC 리더는 비활성화 상태로 대기합니다.
   - **`📱 핸드폰 NFC 태깅 모드 (보조 옵션)`**: 토글을 켰을 때만 갤럭시 뒷면 NFC 리더(`NfcAdapter.enableReaderMode`)가 가동되어 상자 태그(예: 빼빼로 `0B71E55D`)를 직접 읽어 로봇 서버로 전송합니다.
2. **상자 배치 완료 알림 (`POST /api/v1/mobile/box-placed`)**:
   - 사람이 1~4번 상자를 리더기 인식 위치에 가져다 놓은 뒤 버튼을 누르면, 로봇팔이 리더기 스캔 및 피킹 시퀀스로 출동합니다.
3. **15×15 바둑판 그리드 실시간 시각화 (`POST /api/v1/grid/locate`)**:
   - 작업대 4점 영역을 **15×15(225칸)** 바둑판으로 분할하여 현재 물품이 위치한 행·열(`R07_C06`), 1단계 셀 중심 접근 좌표, 2단계 미세 오차(`ΔX, ΔY`), 과자 찌그러짐 방지 안전 하강 높이(`Z`)를 실시간 표시합니다.
4. **완료 햅틱(진동) 피드백**:
   - 로봇이 피킹 후 상자에 물품을 내려놓고 복귀하면 갤럭시 진동(`Vibrator`)과 함께 완료 알림 배너가 표시됩니다.

## 2. 갤럭시에서 사용하는 2가지 방법

### 방법 A: APK 파일 설치 (전용 네이티브 앱)
1. 본 저장소의 **GitHub Actions ➔ `Build Galaxy Remote APK`** 워크플로우 실행 결과에서 **`galaxy-e0509-remote-apk`** 아티팩트를 다운로드합니다 (또는 Android Studio에서 `galaxy_app/` 폴더를 열어 `Build APK(s)` 실행).
2. 다운로드한 `app-debug.apk`를 갤럭시 스마트폰에 전송하여 설치합니다.
3. 앱 상단 입력창에 로봇 PC의 Wi-Fi IP 주소(예: `192.168.0.10:8000`)를 입력하고 **[서버 연결]**을 터치합니다.

### 방법 B: 설치 없이 1초 만에 실행 (갤럭시 Chrome PWA 앱 모드)
1. 로봇 PC에서 `python scripts/start_lab.py --host 0.0.0.0`을 실행합니다.
2. 갤럭시 Chrome 브라우저에서 `http://<로봇PC_IP>:8000/remote` 에 접속합니다.
3. 우측 상단 메뉴(`⋮`) ➔ **[홈 화면에 추가 (앱 설치)]**를 누르면 갤럭시 바탕화면에 전용 앱 아이콘이 생성됩니다.

## 버튼이 로봇을 움직이려면 (로봇 PC 사이클 실행 필수)

앱 버튼은 웹 서버에 명령을 저장할 뿐이고, 실제 동작은 로봇 PC의 `scripts/project_cycle.py --api ...`가 수행한다.
앱 상단 「04 매니퓰레이터 제어」의 연결 표시가 **「로봇 PC 사이클 연결됨」**이어야 버튼이 동작한다.

```
# 리모컨으로 출동시키는 모드: [작업 시작]/[리더기 스캔 출동]/상자 배치 버튼을 누를 때마다 1사이클
python scripts/project_cycle.py --mode real --confirm-real --api http://127.0.0.1:8000 --remote-trigger --cycles 0 --picking-config config/integration.real.json --depth-api http://127.0.0.1:8000
# 태그 대기 모드: 상자 배치 버튼/다른 PC 리더기로 등록된 작업을 처리, [리더기 스캔 출동]은 로봇 리더기로 태그 읽기
python scripts/project_cycle.py --mode real --confirm-real --api http://127.0.0.1:8000 --remote-rfid --cycles 0
```

| 버튼 | 동작 |
|---|---|
| 작업 시작 · 재개 | 대기 중이면 사이클 시작(`--remote-trigger`), 일시정지 중이면 재개 |
| 일시정지 | 다음 동작 전에 멈춤 (진행 중인 한 동작은 끝까지 수행) |
| 리더기 스캔 출동 | 리더기 위치로 이동해 태그를 읽고 작업 시작 |
| 홈 자세 복귀 | 대기 중일 때만 홈 자세로 이동 (사이클 중에는 무시하고 알림) |
| 비상 정지 / 정지 해제 | 즉시 move_stop. 해제는 [정지 해제] 버튼으로만 가능 |

「03 작업 영역」은 교시한 꼭짓점 1~4(BASE mm)를 실제 비율의 직사각형으로 그리고 15×15 셀로 나눈다.
깊이 카메라(`/api/robot/pick/depth-objects`)가 찾은 구역별 물품을 실선 테두리로, 로봇 사이클이 마지막으로 인식한 위치를 점선으로 표시한다.

## 안전 주의 (비상 정지)

- 앱의 **비상 정지**는 로봇 PC에서 `scripts/project_cycle.py ... --api http://127.0.0.1:8000`이 실행 중일 때만 실제 로봇을 멈춘다.
  사이클이 0.3초마다 상태를 확인해 `move_stop`을 보낸다. 사이클이 꺼져 있거나 Wi-Fi가 끊기면 동작하지 않는다.
- 따라서 **펜던트 E-Stop을 대신하지 않는다.** 로봇 주변에는 항상 펜던트를 둔다.
- 비상 정지 후에는 앱에서 `reset_stop`을 누르기 전까지 사이클이 시작되지 않는다.
